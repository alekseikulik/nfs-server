NFS server for Kubernetes

## PV and PVC examples

```yaml
# Example PersistentVolume for NFS Server
---
apiVersion: v1
kind: PersistentVolume
metadata:
  name: nfs-volume
  namespace: demo
spec:
  storageClassName: ""
  capacity:
    storage: 200Gi
  accessModes:
    - ReadWriteMany
  nfs:
    server: nfs-server.nfs.svc.cluster.local
    path: "/srv/nfs/"

# Example PersistentVolumeClaim for NFS Server
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: nfs-volume-claim
  namespace: demo
spec:
  storageClassName: ""
  volumeName: nfs-volume
  accessModes:
    - ReadWriteMany
  resources:
    requests:
      storage: 200Gi

```
