NFS Server has been deployed successfully!

Service: {{ include "nfs-server.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local
NFS Port: 2049

USAGE:

1. Create a PersistentVolume pointing to this NFS server:

   apiVersion: v1
   kind: PersistentVolume
   metadata:
     name: nfs-pv
   spec:
     capacity:
       storage: 10Gi
     accessModes:
       - ReadWriteMany
     nfs:
       server: {{ include "nfs-server.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local
       path: /exports

2. Create a PersistentVolumeClaim:

   apiVersion: v1
   kind: PersistentVolumeClaim
   metadata:
     name: nfs-pvc
   spec:
     accessModes:
       - ReadWriteMany
     resources:
       requests:
         storage: 10Gi
     volumeName: nfs-pv
     storageClassName: ""

3. Mount in your Pod:

   volumes:
     - name: nfs-storage
       persistentVolumeClaim:
         claimName: nfs-pvc
   containers:
     - name: app
       volumeMounts:
         - name: nfs-storage
           mountPath: /data
